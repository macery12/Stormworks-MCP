# v0.4 focus: helm and dashboard

Moved from v0.3, which became the general vehicle builder ([v0.3 plan](v0.3-plan.md)).

Build a usable helm area for generated boats:

- Place gauges for speed, engine RPS, temperature, fuel and battery state.
- Add an ignition key and labeled switches for the systems the boat actually has.
- Wire gauges, keys, switches and seat controls through reusable logic.
- Keep the helm readable and reachable, with the wiring checked before export.
- Verify operation and layout in game on a complete boat.

The v0.2 release establishes the boat hull and powertrain baseline for this work.
