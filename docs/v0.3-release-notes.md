# Stormworks MCP v0.3.0

> **Upgrading from v0.2 or earlier? Remove the old Stormworks MCP entry from your AI client
> before adding the new one.** In Claude Desktop or ChatGPT / Codex, delete the old
> `stormworks` server (and any older `server.py`, extension or portable-EXE setup), close the
> client, then add v0.3 with the installer's "Add to ..." option or the app's
> **MCP > Set up** menu. Two entries for the same server fight over the connection.

## New

- **Installer.** Download the `-setup.exe`: it installs for you only (no admin) or for all
  users, adds a Start menu shortcut, can add itself to Claude Desktop and ChatGPT / Codex, and
  upgrades, repairs or uninstalls an earlier install. The portable EXE is still available.
  Also on winget (`winget install macery12.StormworksMCP`) once the package is accepted.
- **Update check.** The app tells you when a newer release is out (Help menu; it can be
  turned off there).
- **Build any vehicle**, not just boats: land vehicles, aircraft and assemblies, with
  optional style checks instead of fixed rules.
- **Modular engines of any size** (`place_modular_engine`): 1x1, 3x3 or 5x5 parts,
  in-line, boxer or ring layouts, starters, alternators, flywheel and coolant. Preflight
  checks modular engines through the game's couplings.
- **Prefabs**: reuse a saved vehicle, or a box cut out of one, inside another vehicle.
- **Block-built tanks** with litres reported, and read-only **physics estimates** (mass,
  flotation, thrust and lift).
- **Multi-body editing**: every body shown, coloured and editable.

## Fixed

- Closing your AI client no longer leaves `stormworks-mcp.exe --connect` processes running
  in the background; they also exit when the app's server stops.
- Preflight follows power through circuit breakers, relays and diodes, and fluid through
  impeller pumps and catalytic converters; unwired gearboxes are treated as fixed ratios;
  tanks without a saved fluid hold diesel, as in game.
- Microcontrollers keep their position when a vehicle is imported.
